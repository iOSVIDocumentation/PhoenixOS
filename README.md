# PhoenixOS

Ретро-рабочая станция на базе Raspberry Pi Pico 2 (RP2350).

## Возможности
- Графический интерфейс с рабочим столом
- Файловый менеджер с поддержкой SD-карт
- Медиаплеер
- Настройки

## Железо
- Чип: RP2350 (ARM Cortex-M33)
- RAM: 520 КБ
- Экран: ST7789 SPI 320x240
- Хранилище: SD-карта (FAT32)
